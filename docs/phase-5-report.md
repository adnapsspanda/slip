## 二、这一阶段修掉的四个真实缺陷

都不是"加功能"，是"原来就是坏的"：

1. **R47 提示条不会自己消失**：`notice` 根本没有定时器，一直挂到用户下一次操作，
   而且过期提示仍然可点（"撤销"指向早已被覆盖的状态）。
2. **R49 连点两下只变一次**：`handleToggle` 读的是快照状态，两次点击都发同一个目标值——
   典型的丢失更新。用户按两下本意是切回来，结果只变了一次。
3. **R44 Tab 会把焦点甩出便签**：编辑中按 Tab 直接跳出，键盘流中断。
4. **R48 链接会带上中文全角标点**：漏了 `“”‘’（《`，用户贴「见 https://a.com。」会得到坏链接。

## 四、一个方法论教训

R49 做变异验证时，我替换代码的范围算错，脚本**语法报错**——输出里没有 `[FAIL]` 行。
如果只看"有没有 FAIL"，就会误判成"变异没被发现、断言是空的"，进而做出错误结论。

**修正后的纪律：变异验证必须同时看退出码**，确认脚本真的跑起来了，而不只是"没看到红"。
