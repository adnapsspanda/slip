## 本阶段发现并修掉的真缺陷

1. **切换编辑目标丢改动**（R12）：改着 A 去双击 B，A 的改动被静默丢弃、B 也没进入编辑。
   根因是提交逻辑读可变的 `editingId`/`draft`。
2. **粘贴清单写坏格式**（R17）：`- 买发票` 会写成 `- [ ] - 买发票`（双重标记）。
3. **522 行死代码**（R16+R18）：`ViewEvent` 通路前端从未产生过事件，
   却让 `dispatch` 主循环背着 `select!` 与 dirty/due 状态机。

## 过程中的两次环境误判（都已留档）

1. **沙盒导致窗口 `WS_VISIBLE` 恒假**：应用自报 `visible=true`、Win32 说 false。
   用"回退到上一提交同样红"与"`explorer.exe` 启动 `vis=True`"双重证明后确认是环境。
   已写进 `AGENTS.md`。
2. **改了源码没重编 shell**：验证 R17 时看到"改动没生效"，实为跑了旧二进制。
   已把验收脚本的时序守卫从"只比 `ui/dist`"扩展到"也比 Rust 源码"。
