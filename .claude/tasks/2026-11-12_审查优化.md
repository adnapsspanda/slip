# Slip 审查优化执行计划（2026-11-12 第二轮）

## 0. 范围

依据本轮五路子代理审查的结论，按 A–E 批次修复。用户已批准全部执行。
原则不变：每条修复配回归测试，并做「改坏 → 测试变红 → 还原」的变异验证；
PowerShell 门禁只认 `pwsh` 7。

## 1. 批次 A：门禁诚实性（主代理执行）

| 项 | 修法 | 验收 |
|---|---|---|
| A1 `Mask-Comments` URL 绕过 | 增加字符串态（`"`、`'`、反引号）与转义处理；字符串内的 `//` 不再当注释 | 临时 JS 文件写 `const u="http://x"; el.innerHTML=userText;` 必须被抓到；`// el.innerHTML=...` 必须不误报 |
| A2 索引 fail-open | 枚举异常改为抛出；索引为空或缺少根 `Cargo.toml` 直接失败；跳过目录用文件名匹配（修 `target` 顶层被扫描） | 破坏 `Get-SourceIndex` 的根路径必须 exit 1；`target/_probe.rs` 不再被扫描 |
| A3 `check-ci-parity` 覆盖不足 | 13 个关口都有命令片段断言；拒绝 `\|\| true`、`continue-on-error`、`if: false`；增加「必须存在的关口全集」；钩子 `bun install` 改 `--frozen-lockfile` | 删掉 bundle/prettier 命令、加 `\|\| true`、两侧同删一个关口，三种破坏都必须 exit 1 |
| A4 `check-doc-sync` 漏源 | 预算规则改为按文件的正则列表，覆盖手写文档、钩子、`tags.js`、`check-bundle-size.ps1` 自身；源文件缺失/规范断言缺失计为失败 | 改 `tags.js` 或脚本头部的预算数字必须 exit 1 |
| A5 体积门禁只测第一个文件 | 按类型汇总全部 `.css` / `.js`；修脚本头部 70→88 | 放第二个超预算 chunk 必须 exit 1 |
| A6 变异审计恢复 | 用 `rb`/`wb` 与字节比较；接入 Linux CI job | CRLF 文件变异后恢复必须逐字节一致；CI 有该步骤 |
| A7 `check-ui-logic` 比较器 | 用递归深比较替代 `JSON.stringify`（区分 `NaN`/`null`）；结构守卫允许 `check (` | 追加 `check("NaN", NaN, null)` 必须红 |
| A8 前端产物新鲜度 | `build.rs` 比较 `ui/src`、`index.html`、`package.json`、`vite.config.*`、`bun.lock` 的 mtime 与 `dist/index.html`；`package-release` 过期计为失败（`-AllowStaleUi` 放行） | 改 UI 源码后 `cargo check -p slip-shell` 必须报可执行提示 |
| A9 路径可移植性 | `check-bundle-size` 用 `[IO.Path]` 组合路径；`package-release` 去掉硬编码用户路径 | 无 |

## 2. 批次 B：存储提交点与不可逆保护（子代理）

| 项 | 修法 |
|---|---|
| B1 restore 提交点 | 预检产出 `Accepted`；`write_atomic` 成功后直接 `accept` + `sync_dir`，不再 `reload()`；同步失败只记 `DurabilityUnconfirmed` |
| B2 purge 备份被 prune | 先 `prune_backups` 再 `backup_bytes`（apply 同样调整）；确保新备份不会被同一轮 prune 删掉 |
| B3 purge 换行元数据 | 删行后重算 `preferred_terminator` / `ends_with_terminator` |
| B4 purge 错误语义 | 未知 ID 用 `NeedsReload`；新增 `StoreError::NotArchived`，映射 `notArchived` |
| B5 `Busy` 重试 | `write_atomic` 对 `IoKind::Busy` 复用 `retry_delay` 退避；只有非瞬时错误才降级 |
| B6 Noop 可见性 | `Ack` 增加 `changed: bool`；`run_batch` 回填；前端只对真正变化的操作 `markUndone` |

## 3. 批次 C：前端数据安全与生命周期（子代理）

| 项 | 修法 |
|---|---|
| C1 双击输入框 | `beginEdit` 在 `editingId === slip.id` 时直接返回；编辑框 `ondblclick` 阻止冒泡 |
| C2 编辑提交竞态 | 用在途 Promise 替代 `committing` 布尔；并发调用 await 同一 Promise 并返回真实结果 |
| C3 临时状态跨唤出 | `summon()` 清 `armed`（含定时器）、`preview`、`backups`；生命周期表补 `armed` / `preview` |
| C4 归档空态出口 | 「返回列表」由 `showArchived` 决定；整库替换成功后复位 `showArchived` / `preview` |
| C5 `pendingDone` 第三次点击 | 按 id 记录在途计数；只有该 id 无排队请求时才删除意图；纯函数 `shouldDropPendingIntent` |
| C6 Noop 提示 | `handleToggle/Edit/Archive/CompleteMany` 只在 `ack.changed !== false` 时 `markUndone`；补 `notArchived` 文案；删死英文分支 |
| C7 队列覆盖 | 编辑、归档、取消归档、锁定、置顶、恢复、隔离、彻底删除统一走 `mutating.run` |
| C8 热键横幅 | 唤出/窗口 focus 时重取 `hotkey_status` |

## 4. 批次 D：外壳（子代理）

| 项 | 修法 |
|---|---|
| D1 关窗退出 | `CloseRequested` → `prevent_close()` + `hide()` + 复位聚焦标志；托盘「退出」仍是唯一优雅退出入口 |
| D2 热键死角 | 备选失败后依次尝试旧键、默认键；托盘文案从常量派生（不再写死 Win） |
| D3 show/capture 语义 | 「显示 Slip」走不上膛的 `show_on_launch`；「快速唤出捕获」保持 `summon` |
| D4 重 I/O | `external_diff`、`export_markdown`、`corrupt_files`、`corrupt_preview` 下放阻塞线程；`guard_corrupt_path` 先做廉价词法判断再 canonicalize |
| D5 子进程回收 | `platform` 的 `spawn` 起短线程 `wait()`；失败路径留可观察信息 |
| D6 tokio 特性 | 外壳显式声明 `time` |

明确不做：`capabilities/default.json` 的收窄（需要真实 GUI 验证，本轮只记录建议）；`persist_hotkey` 失败可见化（P3，记录）。
